# Olympics-Symbol-Python
Drawing the Olympic Rings Logo with Python

- The program imports the `turtle` module to use the Turtle Graphics window.
- It moves the pen and draws a blue circle with radius 45.
- Similarly, it draws a black circle, a red circle, a brown circle, and a green circle.


## How To Run

```
py OlympicSymbol.py
```
